## 엔진 조건 카드

- **pandas → Dask**: 기존 pandas 스타일을 최대한 재사용하고 병렬/디스크 분할이 필요할 때. API가 완전히 같지는 않음.
- **pandas → Polars**: Lazy/columnar 성능 우선시; API 변환을 감수할 때. Polars는 pandas 그대로가 아님.
- **Ray**: 데이터 크기보다 **분산 모델 학습·튜닝·GPU 활용** 필요가 핵심.
- **Spark MLlib**: 팀/클러스터 기반의 ETL, DataFrame 기반 ML Pipeline, 대규모 통합 처리 시.

**방법론 등록 상태:** 기법 설명과 선택 조건 등록, 전체 통계 계산 엔진 구현/검증은 다음 단계. V1은 데이터 조건 추천과 기본 집계만 실제 구현.
