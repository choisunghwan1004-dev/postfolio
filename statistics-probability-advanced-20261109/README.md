## 고급 기법 (직접 구현)

| 기법 | 질문 | 적용 및 주의 |
|---|---|---|
| 부트스트랩 | 두 프로그램 방문 평균 차이의 불확실성은? | 1만 번 복원추출, 퍼센타일 95% 구간 |
| 순열검정 / 몬테카를로 | 그룹 차이가 관측된 정도로 극단적인가? | 1만 번 무작위 재배열, 양측 검정 |
| 카이제곱 독립성 검정 | 프로그램과 지역은 연관되는가? | 기대빈도 확인 후 해석 |
| 베이즈 Beta-Binomial | 만족도 4점 이상 비율의 사후 추정은? | 명시한 균일 Beta(1,1) 사전분포 |
| 조건부확률 | 프로그램별 만족자 비율은? | P(만족도≥4 | 프로그램) |
| 정보 엔트로피 | 지역 분포가 균등한가? | Shannon entropy (bits) |
| IQR 이상치 플래그 | 방문수가 특이한 행은? | 탐지용 표시, 자동 삭제하지 않음 |
| BH 다중검정 보정 | 검정 여러 개를 수행한 영향을 조정하려면? | 원 p값과 보정 p값 별도 제시 |

## 입력 자료와 정제

입력 파일은 **중복 복사하지 않고** 기존 실습관 CSV를 재사용합니다.

`../data-methods-lab-20261109/data/sports_center_members_demo.csv`

- 총 50행 중 회원 ID 중복 2행을 제거해 **48행**
- 음수 방문수 1건은 결측 처리 후 중앙값 대치
- 결측 만족도 2건을 중앙값으로 대치
- 결측치 처리 방식은 시연용이며 실제 데이터에서는 원인 분석이 우선

## 실제 로컬 실행 결과

Python/pandas/NumPy/SciPy에서 기존 원본 CSV를 읽어 아래 값을 계산했고 6개 unittest를 통과했습니다.
동일 결과 재현을 위해 난수 시드 **20261109**, 반복횟수 **10,000**을 고정했습니다.

| 항목 | 분석값 |
|---|---|
| A 월평균 방문 | 8.541667회 |
| B 월평균 방문 | 10.416667회 |
| B - A | +1.875회 |
| 부트스트랩 95% 구간 | [0.333333, 3.458333]회 |
| 순열검정 양측 p값 | 0.031597 |
| 프로그램-지역 카이제곱 | χ²=0, p=1, 자유도 2 |
| 카이제곱 기대빈도 최솟값 | 8 (기준 5 이상) |
| 지역별 수 | 동·서·중 각각 16명 |
| 지역 엔트로피 | 1.584963 bits (최대치) |
| 만족도 ≥4 조건부확률 | A 5/24 = 0.208333, B 12/24 = 0.5 |
| 베이즈 사후 평균 | A 6/26 = 0.230769, B 13/26 = 0.5 |
| IQR 기준 이상치 플래그 | 없음 |
| BH 보정 | 순열 p 약 0.063194, 지역 카이제곱 p=1 |

**주의:** 순열검정 p값은 그룹의 교환가능성 등의 가정하에서만 해석합니다. 관측 자료이고 무작위 배정이 아니므로 이 결과에서 프로그램 효과의 인과관계를 주장하지 않습니다.
여러 검정을 수행하면 유의성 판단이 달라질 수 있습니다. 지역 변수는 실제 지역 인구 대표성을 뜻하지 않습니다.

## Windows 11 실행

저장소 `postfolio`를 복제한 뒤 루트에서 실행하세요.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r statistics-probability-advanced-20261109/requirements.txt
.\.venv\Scripts\python.exe statistics-probability-advanced-20261109/advanced_analysis.py
.\.venv\Scripts\python.exe -m unittest discover -s statistics-probability-advanced-20261109 -p "test_*.py" -v
```

분석을 실행하면 `statistics-probability-advanced-20261109/results.json` 파일이 생성됩니다.
**검증 문구:** `ADVANCED_ANALYSIS_PASS` 및 `Ran 6 tests ... OK`.

## 분석의 한계 및 AI 사용 표기

- 이 분석에서는 실제 로또 번호의 예측 성능 향상을 주장하지 않습니다.
