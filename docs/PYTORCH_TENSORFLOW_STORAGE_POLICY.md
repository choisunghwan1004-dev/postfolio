- Python 코드, 노트북(대용량 임베디드 실행 출력 제거), requirements, README
- 재현 가능한 소형 예제/공개 CSV, 검증 지표, 분석 결과 JSON

## 용량 초과 시 '화면 표시' 방식
- 실제 학습은 로컬 Python 또는 허가된 실행 환경에서 수행
- 웹페이지에는 저장된 **요약 결과·차트·평가 지표·실행 조건**을 정적 미리보기로 표시
- 모델이 웹에서 실제 실행 중인 것처럼 표시하지 않음
- 필요 시 학습 결과 파일의 저장 위치, 생성 일자, 소스 버전, 데이터 출처를 기록
- 다운로드용 대용량 파일 없이도 과제 평가자가 화면으로 결과를 확인할 수 있도록 구성
