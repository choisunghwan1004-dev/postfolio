# 마음씨앗 숲 분석서

## 현재 구현과 구조

HTML CSS JavaScript SVG와 HTML Audio. 서버 DB와 API 키 없음.

| 항목 | 실제 처리 |
|---|---|
| 입력 | 버튼·검색·선택 및 필요한 사용자 기록 |
| 출력 | 본문·선택 결과·자료·영상 또는 개인 계획 |
| 상태와 저장 | localStorage animal-forest-v1: i 0~10, picks 0 또는 1 배열, phase choose 또는 result, promise 문자열. animal-forest-backup에 새 모험 직전 기록 보관. 이전 글 모험은 별도 seed 계열 키 유지. |
| 예외 | 선택 처리 중 중복 입력을 막고 run 값으로 집으로 이동 후 남은 비동기 전환을 무시한다. 저장 예외는 화면 진행을 계속하며, 음성 재생 실패 시 기기 음성으로 대체를 시도한다. 저장 실패의 명시적 사용자 안내는 보강 여지가 있다. |
| 권한 | 일반 공개 |

## 화면과 이동

시작 → 동물 또는 문 선택 → 문 열림과 동물 이동 → 짧은 결과 → 다음 장소 → 씨앗 정원 → 작은 약속 → 집으로

크림 배경 #fff8e9, 초록 숲, 황갈색과 보라색 문. 폼 대신 큰 동물과 선택 버튼. 650px 이하 CSS 분기 및 동작 줄이기 설정.

## 데이터와 API

localStorage animal-forest-v1: i 0~10, picks 0 또는 1 배열, phase choose 또는 result, promise 문자열. animal-forest-backup에 새 모험 직전 기록 보관. 이전 글 모험은 별도 seed 계열 키 유지.
서버 DB가 없으므로 SQL 테이블·PK/FK·DB 트랜잭션 ERD는 해당 없음입니다. 배포 파일 읽기와 브라우저 저장소는 서버 DB API와 구분합니다.

## 알려진 한계

선택 처리 중 중복 입력을 막고 run 값으로 집으로 이동 후 남은 비동기 전환을 무시한다. 저장 예외는 화면 진행을 계속하며, 음성 재생 실패 시 기기 음성으로 대체를 시도한다. 저장 실패의 명시적 사용자 안내는 보강 여지가 있다.

저장 제한 상태 안내, 실제 아동 사용성 관찰, iPhone·Android 실기기 재생 확인.

## 사용자 확인

사이트를 열어 동물 또는 문 선택 조작을 하고 다음 화면이 나타나는지 확인합니다. 저장이 있는 경우 창을 다시 열어 기록 유지 여부를 봅니다.
