## 자료 출처와 수집 방법

창작 동화와 자체 SVG 동물. 실제 역사 인물이나 사건을 재현하지 않는다. 한국어 일반 합성음성 SunHi. 특정 실존 인물 복제 없음.
자료는 자체 제작 또는 원문 확인 후 편집·게시하는 방식입니다. 출처 목록이 있다는 사실과 최신 원문 재검증 완료를 구분합니다.
