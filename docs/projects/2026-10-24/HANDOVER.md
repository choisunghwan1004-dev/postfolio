# 실행과 인계

## 가장 쉬운 실행

각 README의 사이트 실행 링크를 누릅니다. 별도 설치나 API 키가 없습니다. 휴대폰에서는 PC의 127.0.0.1을 입력하는 방식이 아닙니다.

## Windows 주소 열기 파일

동봉 BAT는 공개 호스팅 주소를 브라우저에서 여는 파일입니다. 로컬 서버나 DB를 자동 시작한다고 표시하지 않습니다. Windows 실기기 실행은 미실행입니다.

## 미디어 확인

README의 영상 재생을 열고 재생 버튼과 스피커를 확인합니다. 브라우저 정책으로 소리가 꺼져 있으면 직접 음소거를 해제합니다. 파일 분석의 오디오 존재 확인과 실제 사용자 기기의 출력 여부는 구분합니다.

## 변경과 복구

소스는 각 사이트의 기존 저장소에서 관리합니다. 이 GitHub 폴더는 문서·영상 링크 모음입니다. 사이트 코드를 포트폴리오 문서 커밋과 혼동하지 않습니다. 과거 버전 복구는 해당 사이트 저장 버전으로 처리하며 접근 권한은 별도로 확인합니다.
