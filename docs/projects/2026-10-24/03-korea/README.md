## 실제 기술

정적 HTML CSS JavaScript와 JSON. 브라우저 fetch로 배포 JSON을 읽는다. 서버 DB와 API 키 없음.

## 자료 출처와 수집 방법

분야별 원문 URL·기관·관측연도·확인일은 industries.json에 저장. 배경·태극·차트는 자체 CSS/SVG. 개별 통계의 최신성 전수 재검증은 이번 문서화 범위에 포함하지 않는다.
자료는 자체 제작 또는 원문 확인 후 편집·게시하는 방식입니다. 출처 목록이 있다는 사실과 최신 원문 재검증 완료를 구분합니다.
