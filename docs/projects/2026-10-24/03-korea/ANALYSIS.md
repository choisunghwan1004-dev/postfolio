# 대한민국 세계를 달리다 분석서

## 현재 구현과 구조

정적 HTML CSS JavaScript와 JSON. 브라우저 fetch로 배포 JSON을 읽는다. 서버 DB와 API 키 없음.

| 항목 | 실제 처리 |
|---|---|
| 입력 | 버튼·검색·선택 및 필요한 사용자 기록 |
| 출력 | 본문·선택 결과·자료·영상 또는 개인 계획 |
| 상태와 저장 | 분류·언어·자료 배열·상세창의 브라우저 상태. industries.json은 14개 분야, cooperation.json은 5개 기록. 원문 수집 자동화나 정기 갱신이 아니라 편집 후 게시된 JSON을 다시 읽는다. |
| 예외 | HTTP 응답과 필수 title·url을 확인한다. 로드 실패는 자료 불러오기 실패로 알린다. 원자료가 없는 연도의 수치를 새로 만들거나 보간하지 않는다. |
| 권한 | 일반 공개 |

## 화면과 이동

언어 선택 → 분야 검색과 필터 → 자료 읽기 → 그래프 기간 선택 → 출처 확인 → 닫고 목록 복귀

기술 파랑·국방 초록·문화 보라 등 목적별 색상 구분. 데스크톱 표와 좁은 화면의 읽기 배치를 구분한다.

## 데이터와 API

분류·언어·자료 배열·상세창의 브라우저 상태. industries.json은 14개 분야, cooperation.json은 5개 기록. 원문 수집 자동화나 정기 갱신이 아니라 편집 후 게시된 JSON을 다시 읽는다.
서버 DB가 없으므로 SQL 테이블·PK/FK·DB 트랜잭션 ERD는 해당 없음입니다. 배포 파일 읽기와 브라우저 저장소는 서버 DB API와 구분합니다.
