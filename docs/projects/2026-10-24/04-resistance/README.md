## 사용 순서

언어·시기 선택 → 사건 목록 → 상세 본문 → 사진 또는 출처 → 닫기·뒤로가기 → 읽던 상태 복귀

## 실제 기술

정적 HTML CSS JavaScript와 자료 카탈로그 JSON. 서버 DB나 API 키 없음.

## 자료 출처와 수집 방법

Wikimedia Commons·USC 등 개별 원문과 기존 권리 표시를 보존한다. rightsStatus source-labelled는 출처 표기 상태이지 이번 문서화에서 권리를 새로 법률 검토했다는 뜻이 아니다. 실제 기록사진과 AI 창작을 혼동하지 않는다.
자료는 자체 제작 또는 원문 확인 후 편집·게시하는 방식입니다. 출처 목록이 있다는 사실과 최신 원문 재검증 완료를 구분합니다.

## 배경 이미지와 로고

큰 사건 목록을 줄이고 작은 사진과 옆 설명을 배치한다. 본문과 확대 사진은 상세 화면에서 읽는다. 휴대폰의 닫기와 복귀 조작을 고려한다.
자체 CSS·SVG와 글자 로고, 외부 사진의 구분은 SOURCES.md에 기록했습니다.
