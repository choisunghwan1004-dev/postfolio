정적 HTML CSS JavaScript와 자료 카탈로그 JSON. 서버 DB나 API 키 없음.

| 예외 | 12초 자료 요청 제한과 안전한 URL·파일명·언어 필드 검사. 갱신 실패 시 기존 자료를 유지하고 다시 시도할 수 있게 한다. 외부 기관의 접속 장애를 내부 버튼 성공과 구분한다. |

## 화면과 이동

언어·시기 선택 → 사건 목록 → 상세 본문 → 사진 또는 출처 → 닫기·뒤로가기 → 읽던 상태 복귀

큰 사건 목록을 줄이고 작은 사진과 옆 설명을 배치한다. 본문과 확대 사진은 상세 화면에서 읽는다. 휴대폰의 닫기와 복귀 조작을 고려한다.

## 데이터와 API

언어는 history-language로 저장한다. 외부 자료 이동 전 읽던 위치·상세·검색·언어를 세션에 보존한다. 카탈로그는 8건이며 title과 desc는 3개 언어 배열이다.
서버 DB가 없으므로 SQL 테이블·PK/FK·DB 트랜잭션 ERD는 해당 없음입니다. 배포 파일 읽기와 브라우저 저장소는 서버 DB API와 구분합니다.

12초 자료 요청 제한과 안전한 URL·파일명·언어 필드 검사. 갱신 실패 시 기존 자료를 유지하고 다시 시도할 수 있게 한다. 외부 기관의 접속 장애를 내부 버튼 성공과 구분한다.
