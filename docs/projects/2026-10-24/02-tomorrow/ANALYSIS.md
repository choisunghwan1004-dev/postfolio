## 화면과 이동

시작 → 상황 읽기 → A 또는 B → 선택 결과 → 이유와 생각 → 다음 단계 → 강점 요약 → 계획 저장

차분한 크림과 짙은 초록 #203d35. 아동용 동물 놀이와 다른 문장 길이와 선택 카드. 700px 이하 세로 배치와 하단 이동 버튼.

## 데이터와 API

localStorage seed-adult와 seed-backup-adult. step 0~10, answers 배열의 pick reason reflection, plan의 self today week month backup, fit 문자열. 서버 계정별 동기화 없음.
서버 DB가 없으므로 SQL 테이블·PK/FK·DB 트랜잭션 ERD는 해당 없음입니다. 배포 파일 읽기와 브라우저 저장소는 서버 DB API와 구분합니다.

## 알려진 한계

normalize로 누락·잘못된 선택값을 정리하고 단계 범위를 제한한다. move의 expected 단계 검사로 오래된 버튼의 중복 이동을 막는다. 저장 제한·클립보드 실패 시 사용자 안내를 제공한다.

선택 횟수 중심 요약의 한계 설명 유지, 실기기 음성 재생과 접근성 점검.
