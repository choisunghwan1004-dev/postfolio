# 그 시절 우리는 한반도 전쟁사

큰 시대 제목만 보이는 목록을 넘어 사건별 배경·전개·영향을 읽고, 관련 자료와 사진을 원문 맥락에 맞춰 탐색한다.

[사이트 실행](https://korean-war-history-atlas.leafytiger512.chatgpt.site) · 접근 범위 접근 제한 custom 유지

## 영상

영상 최종본은 **확인 필요**입니다. 현재 확인된 접근 설정은 custom이다. 사용자 계정 외 일반 방문자의 열람을 공개 완료로 기록하지 않는다.

## 사용 순서

시대·검색 → 장 선택 → 세부 항목 읽기 → 자료 또는 사진 → 뒤로가기 → 상세 또는 목록 복귀

## 실제 기술

HTML CSS JavaScript 및 events.json을 읽는 정적 사이트. 서버 DB·외부 API 키 없음.

## 자료 출처와 수집 방법

국사편찬위원회 우리역사넷, 한국민족문화대백과, Commons 및 Truman Library 등 개별 출처를 events.json과 README에 기록한다. 전근대 관계도는 자체 개념도로 실제 전투 배치가 아니다.
자료는 자체 제작 또는 원문 확인 후 편집·게시하는 방식입니다. 출처 목록이 있다는 사실과 최신 원문 재검증 완료를 구분합니다.

## 배경 이미지와 로고

목록은 작은 제목과 요약, 본문은 넓은 상세 영역. 600px 이하에서 전체 높이 상세와 큰 터치 버튼 및 안전영역 여백.
자체 CSS·SVG와 글자 로고, 외부 사진의 구분은 SOURCES.md에 기록했습니다.
