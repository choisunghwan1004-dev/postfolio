# 그 시절 우리는 한반도 전쟁사 분석서

## 현재 구현과 구조

HTML CSS JavaScript 및 events.json을 읽는 정적 사이트. 서버 DB·외부 API 키 없음.

| 항목 | 실제 처리 |
|---|---|
| 입력 | 버튼·검색·선택 및 필요한 사용자 기록 |
| 출력 | 본문·선택 결과·자료·영상 또는 개인 계획 |
| 상태와 저장 | events.json 12개 장, topics 총 36개. sessionStorage로 읽기 상태를 보존하고 history로 목록·상세·자료·확대 단계를 관리한다. 문서상 ERD는 해당 없음. |
| 예외 | 자료 로드 실패 문구, 상세와 확대 닫기 처리, 원문 주소 복사와 새 탭 대안. 같은 창 이동·_top 제거 등 개정 이력은 최신 source 코드와 구분해 기록한다. |
| 권한 | 접근 제한 custom 유지 |

## 화면과 이동

시대·검색 → 장 선택 → 세부 항목 읽기 → 자료 또는 사진 → 뒤로가기 → 상세 또는 목록 복귀

목록은 작은 제목과 요약, 본문은 넓은 상세 영역. 600px 이하에서 전체 높이 상세와 큰 터치 버튼 및 안전영역 여백.

## 데이터와 API

events.json 12개 장, topics 총 36개. sessionStorage로 읽기 상태를 보존하고 history로 목록·상세·자료·확대 단계를 관리한다. 문서상 ERD는 해당 없음.
서버 DB가 없으므로 SQL 테이블·PK/FK·DB 트랜잭션 ERD는 해당 없음입니다. 배포 파일 읽기와 브라우저 저장소는 서버 DB API와 구분합니다.
