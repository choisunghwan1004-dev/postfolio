# 그 시절 우리는 한반도 전쟁사 출처와 이용 조건

## 데이터 출처

국사편찬위원회 우리역사넷, 한국민족문화대백과, Commons 및 Truman Library 등 개별 출처를 events.json과 README에 기록한다. 전근대 관계도는 자체 개념도로 실제 전투 배치가 아니다.

## 수집 방법과 시점

2026-10-24 현재 배포 소스와 제작 노트를 대조했습니다. 원문을 새로 전수 수집한 작업이 아닙니다. 데이터 항목의 기준일·checked 필드와 이번 문서 확인일을 구분합니다.

## 배경 이미지와 로고

자체 제작 CSS·SVG·문자 로고와 외부 역사 사진을 구분합니다. 외부 사진을 쓰는 역사 프로젝트에서는 각 자료의 credit·url·rightsStatus·reviewNote를 유지합니다.

## 음성 음악과 AI

영상이 있는 경우 합성음성과 자체 코드 음악, AI 생성 삽화 또는 자체 2D 그림을 구분합니다. 모델 이름을 확인하지 못한 생성 이미지는 모델 미확인으로 남깁니다. 'pastai'는 실제 제품이 확인되지 않아 사용 기술로 기록하지 않습니다. 실행 중 OpenAI API가 있다고 가정하지 않습니다.

## 이용 조건 확인 상태

출처 표기와 제작 방식은 확인했습니다. 개별 외부 사진·음성 서비스·폰트의 상업 이용 및 재배포 조건 전수 재확인은 확인 필요입니다. 무료·AI 제작이라는 이유만으로 허가를 추정하지 않습니다. 상세 원문 주소는 기존 자료 파일과 Production_Notes에 보존합니다.
