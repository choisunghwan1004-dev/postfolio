# 함께 짓는 내일 분석서

## 현재 구현과 구조

HTML CSS JavaScript, HTML video 및 timeline.json. 기록 보관은 브라우저 localStorage. 외부 API를 실시간 호출하지 않는다.

| 입력 | 버튼·검색·선택 및 필요한 사용자 기록 |
| 출력 | 본문·선택 결과·자료·영상 또는 개인 계획 |
| 상태와 저장 | 관심 기록은 together-records-v1 배열로 저장하고 유효한 사례 ID만 남긴다. 장면 시작과 길이는 assets/timeline.json을 읽는다. 클라우드 계정 동기화 없음. |
| 예외 | 장면 목록을 못 읽어도 영상 열람은 별도로 안내한다. 클립보드 실패 시 주소 입력창 선택과 직접 복사를 안내한다. 새 탭 실패와 내부 자료 요약 열람을 구분한다. |
| 권한 | 일반 공개 |

## 화면과 이동

영상 또는 사례 선택 → 장면·본문 읽기 → 출처 핵심 보기 → 필요 시 원문 → 닫고 복귀 또는 관심 기록 저장

세로 영상과 사례 카드 및 따뜻한 식사·일하는 손의 삽화. 실존 인물의 현장 기록사진으로 표시하지 않는다.

## 데이터와 API

관심 기록은 together-records-v1 배열로 저장하고 유효한 사례 ID만 남긴다. 장면 시작과 길이는 assets/timeline.json을 읽는다. 클라우드 계정 동기화 없음.
서버 DB가 없으므로 SQL 테이블·PK/FK·DB 트랜잭션 ERD는 해당 없음입니다. 배포 파일 읽기와 브라우저 저장소는 서버 DB API와 구분합니다.

## 알려진 한계

장면 목록을 못 읽어도 영상 열람은 별도로 안내한다. 클립보드 실패 시 주소 입력창 선택과 직접 복사를 안내한다. 새 탭 실패와 내부 자료 요약 열람을 구분한다.

현지 운영과 비용·수익의 실제 기록, 참여자 동의가 있는 인터뷰, 장기 성과 후속 확인.

## 사용자 확인

사이트를 열어 장면·본문 읽기 조작을 하고 다음 화면이 나타나는지 확인합니다. 저장이 있는 경우 창을 다시 열어 기록 유지 여부를 봅니다.
