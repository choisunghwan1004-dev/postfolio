## Windows 11 + VS Code 사용법

1. ZIP의 모든 파일을 `C:\workspace\election-newsroom-demo` 같은 폴더로 압축 해제.
2. VS Code에서 **File → Open Folder**로 해당 폴더 열기.
3. 터미널(PowerShell)에서 다음 명령 실행:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe server.py
```

4. 브라우저에서 **http://127.0.0.1:8502** 열기.

간편 실행: Windows에서 `start_windows.bat` 더블클릭. 실행 정책 또는 바이러스 백신이 막으면 위 PowerShell 명령으로 수동 실행합니다.

중지: VS Code 터미널에서 `Ctrl+C`.

### 테스트

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

개발 환경 Python 3.13 + FastAPI + pytest에서 **17개 PASS**. 사용자 Windows/모바일 실기기 테스트는 아직 실행하지 않았습니다.

### 실제 사용 흐름

1. **전국 개표 종합:** 전체 후보, 지도 대신 17개 지역 타일, 지역별 득표 집계 확인.
2. **지역·선거구 탐색:** 지역 선택 → 가상 선거구 목록 → 한 선거구 후보별 표수 확인.
3. **RAG 기사·검증:** 범위 선택 → 초안 생성 → 근거 원장 → 필요시 근거 검색 → 규칙 검사 → 사람 승인. 일부러 문장 숫자나 지역을 바꾸면 승인이 차단됩니다.
4. **방송 CG·대본:** 16:9 자료화면과 동적 대본 확인.

## 현실적인 데이터/AI 연계 설계

- `data/mock_documents.json`: 교육용 출처 5개를 보관. 현 단계에는 외부 기관 발행 문서를 사용하지 않음.
- `/api/snapshot`: 서버 합성 개표 자료, 기준 시각, 집계 단계와 출처 표시.
- `/api/export/districts.csv`: CSV 교육용 합성 데이터 내보내기.
- `/api/rag/search?question=기사%20승인`: 문서 키워드 검색. **임베딩 검색 아님**.
- `/api/articles/draft`: 스냅샷을 봉인한 초안·증거 원장 생성.
- `/api/articles/{id}/review`: 불일치 승인 차단, 이유 있는 수동 승인.
- `/api/audit`: 기사 생성/승인/차단 최근 기록.
- `/ws`: WebSocket으로 시뮬레이션 갱신 전송.
