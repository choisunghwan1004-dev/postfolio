# 선거방송 V0.2 사진·CG 우선 개발 기록

기존 V0.1의 모의 개표·WebSocket·RAG 근거 검색·승인 차단·방송 CG 코드는 보존하고 사진·그래픽 자료실을 추가한 **영상 제작 보류 버전**입니다.

## 이번 단계에서 완료
- AI 생성 가상 앵커 사진 1점(실존 인물 아님)
- 자체 제작 개표상황실·지역 현황 CG 2점
- 사진/CG 3점의 원본과 출처·권리·SHA-256 기록
- 20분 종합뉴스 구성 장면표 CSV, 앵커 대본, 지침서 체크리스트
- 사진 갤러리·다운로드·로컬 미리보기 (사용자 파일은 서버 미전송)
- 기존 '방송 CG·대본'과 개표 대시보드 기능 유지

## 이번 단계에서 하지 않는 일
- **MP4 동영상 제작·제공·배포: 보류**
- 20분 뉴스 음성·자막·FHD 최종 렌더링: 보류
- 공식 선관위 실시간 개표 연동, LangChain 실제 벡터 RAG: 미구현

자료실에 영상 자리표시자만 남겼습니다. 향후 사용자가 동영상 제작을 재개할 때 연결할 수 있습니다. 기존 로컬 동영상 미리보기 입력 기능은 제거하지 않았습니다.

## Windows 사용
`py -3.12 -m venv .venv` → `.\.venv\Scripts\python.exe -m pip install -r requirements.txt` → `.\.venv\Scripts\python.exe server.py` → 브라우저 `http://127.0.0.1:8502`.

## 원본 보존
프로젝트 V0.1은 기존 GitHub 경로에 유지. 새로운 사진·CG 우선 버전은 별도 버전으로 관리합니다.
