## 1. 과제 목적
수업 Olist 데이터 분석 사실표·모델 설명서·교육용 가상 판매자 규정을 근거 책장으로 만들어 질문에 답하는 RAG 챗봇의 구조와 검수 과정을 공부했다. 기존 20셀 Jupyter 노트북, 기존 Olist 대시보드를 원본 상태로 보존하고 독립 코드로 분리했다.

## 3. 기능
자료→LangChain Document→임베딩→A/B/C 벡터 저장소→유사도 검색→ChatPromptTemplate→ChatOpenAI→StrOutputParser→근거 ID 검사→Streamlit.

A는 F, B는 F+M, C는 F+M+R을 허용한다. `ask(question, channel, api_key, k=4)`가 사용한다. 정규식 `r"\[([FMR]\d{2})\]"`로 답변 인용을 검색 근거 ID와 비교한다. 없는 ID 인용이나 근거 누락 시 답변을 차단한다. **일치하는 ID가 있다고 해당 문장의 사실성이 자동 검증되는 것은 아니다.**

## 6. 해석과 배운 점
모델은 검색 문맥이 없으면 그럴듯한 잘못된 답을 만들 수 있다. 출처 ID, 원문 사실표, 원본 계산, 기자의 최종 승인을 별도 단계로 확인해야 한다. 실제 Olist 정책과 수업용 가상 규정을 혼동해서는 안 된다.
