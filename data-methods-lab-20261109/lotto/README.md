## Windows 재실행

이 폴더에서 Python 3.12 환경을 사용하세요.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe analysis.py
.\.venv\Scripts\python.exe -m notebook
```

**로또 원본 전체 CSV는 웹페이지에서 직접 공개하지 않았고**, 분석에 사용한 300회차의 필요한 열만 추출했습니다. 상금/판매액은 공개된 과거 데이터의 일부지만 최신 원자료 대조를 수행한 것은 아닙니다.

## 교육·언론 검수

- **시간순 백테스트**는 각 미래 추첨을 계산에 사용하지 않고 그 전에 나온 60회차만 활용.
- 난수 시드 고정으로 예제 재현이 가능하나, 시드·기간·평가 지표를 바꾸면 성능도 달라짐.
- 과거 번호 빈도나 ML로 **미래 당첨 확률이 올라간다는 증거가 없음**. 모든 특정 조합의 1등 확률은 동일.
- 로또 구매자나 지역별 실제 소비 데이터를 확보하지 않았으므로 RFM, 10만명당, 지도, TF-IDF는 **별도의 인공 데이터**로만 시연.
- 사전 AI 코드 보조를 사용했으며 숫자와 최종 결과는 원본 자료와 실행 결과를 기반으로 검수.
