# K-pop 실제 데이터 분석 — 실행 결과 (2026-11-09)

**원출처:** https://www.kworb.net/spotify/country/kr_weekly.html — Spotify Weekly Chart South Korea **2026/11/05**. 이 데이터는 독립 수집처인 Kworb가 공개한 통계입니다(Spotify 공식 API 직접 조회 결과 아님).

**K-pop GitHub 원본**: https://github.com/dominickim77-ui/mbc-kpop-data (2026-11-09 404 확인). 이 원본의 `kpop_comparison.csv`는 확보하지 못했으므로, 아래 분석은 **대체 국내 주간 차트**를 이용한 독립 실습입니다.

## 데이터 상태

- 관측값: 한국 Spotify 주간 차트 1~20위, **20곡** (장르 필터 없음, K-pop만으로 구성된 자료 아님).
- 데이터 컬럼: 순위, 가수, 곡명, 주간 재생수, 전주 대비 증감수, 비교 날짜, 출처 URL.
- 중복 순위 0, 결측 주간 재생수 0, 신규 진입에 따른 전주 증감수 결측 **1건** (정상 처리).
- 이전 주 재생수는 `당주 재생수 - 증감수`로 계산. 신규 진입 곡에는 전주 수치를 채우지 않음.
