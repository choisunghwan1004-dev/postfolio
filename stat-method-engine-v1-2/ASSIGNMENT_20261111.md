# 과제 — 데이터 조건과 통계기법을 바꿔가며 결과 검증하기

## 1. 목적
동일한 데이터를 사용하더라도 분석 기간·임계값·집단·방법을 바꾸면 결과가 달라진다는 것을 직접 확인한다. 수업 `ai-datajournalism-labs`의 시각화 기초와 차트 문법을 참고했고, 기존 통계 엔진 V1.1을 유지하면서 V1.2의 시나리오 실행기를 개발했다.

## 2. 입력 자료·출처
- 입력: 수업 제공 `data_air_2022.csv`, 인코딩 CP949
- 데이터 열: `location`, `day`, `so2`, `co`, `o3`, `no2`, `pm10`, `pm25`
- 원본 범위: 종로구 673행(2022년 4~12월 자료)
- 원본 GitHub: https://github.com/journal-izm/ai-datajournalism-labs
- 내 GitHub 보관본: https://github.com/choisunghwan1004-dev/postfolio/tree/main/course-source/ai-datajournalism-labs
- 수업 강의 코드는 참고용이며 새 모듈·기존 원본 보존 정책을 분리하였다.

## 3. 분석 가설 및 조건
- Q1: PM10의 전체 평균은? → 기술통계 / 숫자열·유효 행 필요
- Q2: PM10≥35인 날만 보면? → 필터+기술통계 / 비교 모집단 변화 주의
- Q3: 여름(6~8월)은? → 기간 필터+기술통계 / 기간 간 계절성 주의
- Q4: 7일 이동평균은? → 날짜 열+일 단위 정렬 필요 / 초기 6일 값 없음
- Q5: PM10·PM25가 함께 움직이나? → Pearson/Spearman / 상관 ≠ 인과
- Q6: 관측소별 집단 차이는? → 관측소 그룹 / 종로구 1개만 있으므로 지역차 비교 불가

## 4. 실제 검증 결과
| 조건 | 방법 | 유효 행 | 결과 |
|---|---|---:|---|
| 전체 | PM10 평균 | 673 | 33.0981 |
| PM10≥35 | 조건부 평균 | 221 | 55.9140 |
| 2022년 6~8월 | 기간별 평균 | 92 | 21.3587 |
| 일자별 | 7일 이동평균 | 673 | 673개 값, 초기 6개 이동평균 결측 |
| PM10 vs PM25 | Pearson 상관 | 673 | r≈0.6985 |
| 관측소별 | 집단별 평균 | 673 | 1개 집단(종로구) |

이 값은 프로그램에서 원본 CSV로 직접 계산했다. 농도 단위 등 외부 해석은 자료사전과 검증 필요. 다른 기간·기준의 평균은 같은 모집단을 비교한 것이 아니다.

## 5. 조건 변경 화면과 개발 범위
`app_streamlit.py`의 기존 1·2번 설정/추천은 보존하고 3번 **조건을 바꾸며 기법 비교하기**를 추가했다. 기법 선택, 날짜/그룹/동등조건/값 범위/이동평균 기간, 실행, 12회 비교, JSON 다운로드 기능을 구현했다. 필수 열 부족, 상관의 상수열, 날짜 역전, 너무 큰 CSV를 차단한다.

## 6. 테스트와 한계
- Python unittest 32개 통과. 실측 데이터로 조건 6개 계산, 파일 SHA-256 원본 변경 없음.
- Streamlit 화면 브라우저 실행·사용자 Windows 캡처 미검증.
- Dask/Polars/Ray/PySpark 실분산 엔진 및 REA 조사 결과 미검증.
- 상관·이동평균은 인과관계 또는 장래 예측을 입증하지 않음.
- 이 과제는 **최종 실서비스 승인 전 개발·검증 후보**임.

## 7. 결론
데이터와 목적에 맞춰 분석법을 선택하고 조건을 바꾸며 결과를 다시 계산해야 한다. 조건별 결과는 표본 범위 및 통계기법의 전제가 달라질 수 있어 함께 검수해야 한다.

**AI 사용 표시:** AI가 코드·보고서 초안을 작성했으며, 실제 파일 실행 수치의 독립 검산과 최종 제출 승인은 사용자 책임으로 남긴다.
